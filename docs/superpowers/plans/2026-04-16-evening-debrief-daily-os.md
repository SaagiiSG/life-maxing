~# Evening Debrief Daily OS — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a three-component daily OS — an evening-debrief skill that converts a natural conversation into a structured Obsidian daily note, a calendar-blocker agent that time-blocks tomorrow's Google Calendar from that note, and a dashboard-updater agent that tracks XP/levels/streaks and rewrites the Obsidian dashboard.

**Architecture:** User debriefs with Claude Code in natural language each evening. When they say a trigger phrase ("that's it for today" / "wrap it up" / "chat is over"), the evening-debrief skill fires inside the same session, reads the conversation, writes a structured daily note to Obsidian, and instructs the user to trigger two downstream agents. The calendar-blocker agent reads the daily note and creates Google Calendar time blocks respecting a 10am–midnight work window and existing events. The dashboard-updater agent reads the daily note and the gamification state file, calculates XP earned, updates the state, and rewrites the Obsidian Dashboard note.

**Tech Stack:** Claude Code skills (SKILL.md), Claude Code agent YAMLs, Obsidian MCP (`mcp__obsidian__*`), Google Calendar MCP (`mcp__0c6a6bb9-ad92-4f80-a14a-ca42e9c6499b__gcal_*`), Markdown templates.

# Evening Debrief

You are running the evening debrief routine for Saagii's Life Maxing OS.

## Your Job

Read back through this conversation. The user has been telling you about their day — what they did, what they skipped, what came up. Now turn that into a structured Obsidian daily note.

Identify:
- **Done**: Everything the user said they completed or did today. Include tasks from any of the 4 areas: Business, Content, AI Tutorials, Academic/SAT.
- **Didn't do**: Anything the user said they planned to do but didn't, or tasks they mentioned skipping or bumping.
- **Needs to be done**: Carry-forward items + anything new that came up that needs action.
- **#1 Priority Tomorrow**: The single most important thing based on Q2 goals (hint: usually Business or AI Tutorials).
- **AI tutorial videos**: Count if the user mentioned completing any. Note the count.

## Step 2: Write the daily note

Create a note in Obsidian at path: `00-RAW/Daily/{{today's date as YYYY-MM-DD}}.md`

Use this exact structure:

```markdown

## ✅ Done Today
{{bullet list of everything done — be specific, use the user's own words}}

## ❌ Didn't Do (was on plan)
{{bullet list of planned things that didn't happen}}

## 📋 Needs To Be Done
{{carry-forward items + new items}}

## 🎯 #1 Priority Tomorrow
{{single most important thing — one line}}

## 💬 Notes / Reflections
{{any key insight, mood, or context the user mentioned}}

---
*AI Tutorials completed today: {{number or 0}}*
*Generated by evening-debrief · {{YYYY-MM-DD}}*

## Step 3: Confirm to the user

After writing the note, tell the user:

> You can trigger them by opening a new Claude Code session and saying:
> "Run the calendar-blocker agent" or "Run the dashboard-updater agent"

## Notes

- Keep the daily note under 50 lines.
- Do not add motivational fluff. Be factual and honest.
- If the user didn't mention something specific for a section, write "Nothing noted."
- The note is the source of truth for the two downstream agents — be accurate.

## Task 5: Calendar Blocker Agent

**Files:**
- Create: `brain/agents/calendar-blocker.yaml`

This agent reads the daily note and creates tomorrow's time blocks in Google Calendar. It respects existing events (gym, work) and uses cognitive load ordering (hardest task first at 10am).

- [ ] **Step 1: Create the agent YAML**

Write `brain/agents/calendar-blocker.yaml` with this exact content:

```yaml
name: calendar-blocker
type: triggered
trigger: manual
description: >
  Reads today's daily note from Obsidian and creates time blocks
  in Google Calendar for tomorrow. Respects existing events.
  Run each evening after the debrief is complete.

prompt: |
  You are Saagii's calendar-blocker agent. Your job: read tonight's
  daily note, understand what needs to get done tomorrow, and fill
  tomorrow's Google Calendar with focused time blocks.

  ## Constraints (non-negotiable)
  - Work window: 10:00am – 12:00am (midnight)
  - Deep work (hardest task): 10:00am – 12:00pm
  - NEVER book past midnight
  - NEVER overwrite existing events (gym, meetings, existing blocks)
  - AI Tutorial Videos: always block 1.5 hours, flexible time (afternoon preferred)
  - Leave at least 30 min buffer between blocks for transition/rest

  ## Cognitive Load Hierarchy
  - 10:00am–12:00pm → Deep work: #1 Priority task (hardest, most important)
  - 12:00pm–1:00pm → Lunch break (do not block)
  - 1:00pm–3:00pm → Medium work: Business tasks, agency work
  - 3:00pm–5:00pm → AI Tutorial Videos (1.5h block within this window)
  - 5:00pm–8:00pm → Content work: IG posts, scripts, filming
  - 8:00pm–12:00am → Light work: admin, planning, Obsidian updates

  ## Steps

  1. Get today's date and calculate tomorrow's date.

  2. Use the Obsidian MCP to read the daily note:
     - Path: `00-RAW/Daily/{{today's date YYYY-MM-DD}}.md`
     - Extract: "Needs To Be Done" list and "#1 Priority Tomorrow"

  3. Use Google Calendar MCP to list tomorrow's existing events:
     - Check all-day and timed events
     - Note any gym blocks, meetings, or existing time blocks
     - Do NOT create events that conflict with existing ones

  4. Create time blocks for tomorrow using Google Calendar MCP:
     - Title format: "🔴 [Deep Work] {task name}" for #1 priority
     - Title format: "🟡 [Work] {task name}" for business/medium tasks
     - Title format: "🎥 [AI Tutorials] 1.5h video block" for tutorial time
     - Title format: "📱 [Content] {task name}" for IG/content work
     - Title format: "⚙️ [Admin] {task name}" for light tasks

  5. Confirm to the user:
     - List every block you created (time + title)
     - Flag any task that couldn't be scheduled (calendar too full)
     - If a task has appeared in "Didn't Do" for 2+ consecutive days,
       note it: "⚠️ Bumped again: {task}" — do not create a block for
       it without the user's explicit instruction.

  ## Important
  - If the daily note doesn't exist yet, stop and tell the user:
    "No daily note found for {date}. Run the evening-debrief skill first."
  - Use judgment on block length: a "write IG script" task = 45 min,
    "record reel" = 1 hour, "respond to client emails" = 30 min.
    Default to 45 min for unspecified tasks.

outputs:
  - google_calendar: "tomorrow's time blocks"
```

**Files:**

- [ ] **Step 1: Create the agent YAML**

Write `brain/agents/dashboard-updater.yaml` with this exact content:

```yaml
name: dashboard-updater
type: triggered
trigger: manual
description: >
  Reads today's daily note, calculates XP earned, updates gamification
  state, and rewrites the Obsidian Dashboard. Run each evening after
  the evening-debrief skill has created the daily note.

prompt: |
  You are Saagii's dashboard-updater agent. Run each evening after
  the evening-debrief skill has written the daily note.

  ## XP Rules (from gamification schema)
  - Each completed task in "Done Today": +10 XP
  - Each AI tutorial video completed (check note footer): +25 XP
  - If "Didn't Do" section is empty (all planned items done): +50 XP bonus
  - If streak hits a 7-day milestone: +100 XP one-time bonus

  ## Level Thresholds
  - Lv 1 Beginner:  0–499 XP
  - Lv 2 Builder:   500–999 XP
  - Lv 3 Grinder:   1,000–1,999 XP
  - Lv 4 Creator:   2,000–3,999 XP
  - Lv 5 Machine:   4,000+ XP

  ## Steps

  ### 1. Read today's daily note
  Use Obsidian MCP to read: `00-RAW/Daily/{{today YYYY-MM-DD}}.md`
  If not found: stop and say "No daily note found for {date}. Run evening-debrief first."

  Extract:
  - Count of bullet points under "✅ Done Today" → task_count
  - Count of bullet points under "❌ Didn't Do" → missed_count
  - AI Tutorials completed today (from note footer line) → video_count
  - #1 Priority: was it in the Done Today section? → priority_done (true/false)

  ### 2. Read gamification state
  Use Obsidian MCP to read: `00-RAW/gamification/state.md`

  If the file doesn't exist, create it with these starting values:
  ```
  xp: 0
  level: 1
  level_name: Beginner
  streak: 0
  last_debrief_date: null
  total_videos: 0
  weekly_videos: 0
  weekly_video_reset_date: {{start of current week YYYY-MM-DD}}
  xp_log: []
  ```

  ### 3. Calculate XP earned today
  ```
  xp_today = (task_count * 10) + (video_count * 25)
  if missed_count == 0: xp_today += 50
  ```
  Check streak:
  - If last_debrief_date == yesterday: streak += 1
  - Else if last_debrief_date is null: streak = 1
  - Else: streak = 1 (reset — gap in debrief)

  If (streak % 7 == 0) and streak > 0: xp_today += 100  # milestone bonus

  ### 4. Update totals
  ```
  new_xp = current_xp + xp_today
  new_total_videos = total_videos + video_count
  new_weekly_videos = weekly_videos + video_count  # reset if week changed
  ```
  Determine level from new_xp using thresholds above.
  Calculate xp_to_next_level = next_threshold - new_xp (or "MAX" at Lv 5).
  Calculate xp_progress_pct = (new_xp - current_level_min) / (current_level_max - current_level_min) * 100.
  Build a 10-char XP bar: "████████░░" (filled = percent / 10, rounded).

  ### 5. Update gamification state in Obsidian
  Rewrite `00-RAW/gamification/state.md` with updated values:
  ```markdown
  # Gamification State

  xp: {{new_xp}}
  level: {{level_number}}
  level_name: {{level_name}}
  streak: {{streak}}
  last_debrief_date: {{today}}
  total_videos: {{new_total_videos}}
  weekly_videos: {{new_weekly_videos}}
  weekly_video_reset_date: {{start of current week}}

  ## XP Log
  | Date | Action | XP | Total |
  |------|--------|----|-------|
  {{prepend today's entry, keep last 30 entries}}
  ```

  ### 6. Rewrite Dashboard.md
  Use Obsidian MCP to rewrite `Dashboard.md` in the vault root:

  ```markdown
  # 🎮 Life Maxing Dashboard

  > Updated nightly by dashboard-updater.

  ---

  ## ⚡ Status

  | Metric | Value |
  |--------|-------|
  | **Level** | {{level}} — {{level_name}} |
  | **XP** | {{new_xp}} / {{next_threshold}} |
  | **XP Bar** | {{xp_bar}} {{xp_progress_pct}}% |
  | **Streak** | {{streak}} days 🔥 |
  | **Videos This Week** | {{weekly_videos}} (~${{weekly_videos * 11}}) |
  | **Total Videos** | {{total_videos}} (~${{total_videos * 11}} total) |

  ---

  ## 🎯 Today's #1 Priority

  {{#1 priority from daily note — with ✅ if done, ❌ if missed}}

  ---

  ## 📋 Bumped Tasks

  {{List any task that has appeared in "❌ Didn't Do" in the last 3 daily notes.
    Read the last 3 daily notes to check. List as "- {task} (bumped {n} days)"
    If none: write "None — clean slate 💪"}}

  ---

  ## 📊 This Week

  {{Build the week table by reading Mon–today's daily notes.
    For each day: count Done items, count Missed items, XP earned.
    Days not yet debriefed: show "—"}}

  | Day | Done | Missed | XP Earned |
  |-----|------|--------|-----------|
  | Mon | ... | ... | ... |
  | Tue | ... | ... | ... |
  | Wed | ... | ... | ... |
  | Thu | ... | ... | ... |
  | Fri | ... | ... | ... |
  | Sat | ... | ... | ... |
  | Sun | ... | ... | ... |

  ---

  ## 🏆 XP Log (Last 7 Days)

  {{Last 7 entries from the XP log in gamification state}}

  | Date | Action | XP | Total |
  |------|--------|----|-------|

  ---

  *Last updated: {{today YYYY-MM-DD}}*
  ```

  ### 7. Report to user
  Print a summary:
  ```
  ✅ Dashboard updated!

  Today: +{{xp_today}} XP earned
    └ {{task_count}} tasks × 10 XP = {{task_count * 10}}
    └ {{video_count}} videos × 25 XP = {{video_count * 25}}
    {{if bonus: └ All-done bonus: +50 XP}}
    {{if streak milestone: └ Streak milestone ({{streak}} days): +100 XP}}

  Total XP: {{new_xp}} | Level {{level}} — {{level_name}}
  Streak: {{streak}} days 🔥
  {{if level up: 🎉 LEVEL UP! You're now Level {{level}} — {{level_name}}!}}
  ```

outputs:
  - obsidian: "00-RAW/gamification/state.md"
  - obsidian: "Dashboard.md"
```
