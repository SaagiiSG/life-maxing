# Evening Debrief

You are running the evening debrief routine for Saagii's Life Maxing OS.

## Your Job

Read back through this conversation. The user has been telling you about their day — what they did, what they skipped, what came up. Now turn that into a structured Obsidian daily note.

## Step 1: Extract from the conversation

Identify:
- **Done**: Everything the user said they completed or did today. Include tasks from any of the 4 areas: Business, Content, AI Tutorials, Academic/SAT.
- **Didn't do**: Anything the user said they planned to do but didn't, or tasks they mentioned skipping or bumping.
- **Needs to be done**: Carry-forward items + anything new that came up that needs action.
- **#1 Priority Tomorrow**: The single most important thing based on Q2 goals (hint: usually Business or AI Tutorials).
- **AI tutorial videos**: Count if the user mentioned completing any. Note the count.

## Step 2: Write the daily note

Create a note in Obsidian at path: `00-RAW/Daily/{{today's date as YYYY-MM-DD}}.md`

Use this exact structure:

```markdown
# Daily Note — {{YYYY-MM-DD}}

## ✅ Done Today
{{bullet list of everything done — be specific, use the user's own words}}

## ❌ Didn't Do (was on plan)
{{bullet list of planned things that didn't happen}}

## 📋 Needs To Be Done
{{carry-forward items + new items}}

## 🎯 #1 Priority Tomorrow
{{single most important thing — one line}}

## 💬 Notes / Reflections
{{any key insight, mood, or context the user mentioned}}

---
*AI Tutorials completed today: {{number or 0}}*
*Generated by evening-debrief · {{YYYY-MM-DD}}*
```

## Step 3: Run the calendar-blocker

Immediately after writing the daily note, run the calendar-blocker agent inline:

1. Get tomorrow's date.
2. Use Google Calendar MCP to list tomorrow's existing events.
3. Read the "#1 Priority Tomorrow" and "📋 Needs To Be Done" from the note you just wrote.
4. Create focused time blocks for tomorrow using these rules:
   - Work window: 10:00am – 12:00am (midnight) only
   - 10:00am–12:00pm → Deep work: #1 Priority (🔴 [Deep Work] {task})
   - 12:00pm–1:00pm → Lunch (do not block)
   - 1:00pm–3:00pm → Medium work: business/agency tasks (🟡 [Work] {task})
   - 3:00pm–5:00pm → AI Tutorial Videos — 1.5h block (🎥 [AI Tutorials] 1.5h video block)
   - 5:00pm–8:00pm → Content: IG posts, scripts, filming (📱 [Content] {task})
   - 8:00pm–12:00am → Light: admin, planning (⚙️ [Admin] {task})
   - NEVER overwrite existing events. Leave 30 min buffer between blocks.
   - Default task length: 45 min. Videos: 1.5h. Recording: 1h.
5. List every block created. Flag any task that couldn't fit. Note bumped tasks (appeared in ❌ Didn't Do 2+ days) with ⚠️.

## Step 4: Run the dashboard-updater

After calendar blocking is done:

1. From the daily note you wrote, count:
   - `task_count` = bullet points under ✅ Done Today
   - `missed_count` = bullet points under ❌ Didn't Do
   - `video_count` = AI Tutorials completed today (from note footer)

2. Read `00-RAW/gamification/state.md` via Obsidian MCP. If it doesn't exist, create it with: `xp: 0, level: 1, level_name: Beginner, streak: 0, last_debrief_date: null, total_videos: 0, weekly_videos: 0`.

3. Calculate XP:
   ```
   xp_today = (task_count × 10) + (video_count × 25)
   if missed_count == 0: xp_today += 50  # all-done bonus
   ```
   Streak: increment if last_debrief_date == yesterday, else reset to 1.
   If streak % 7 == 0 and streak > 0: xp_today += 100  # milestone bonus

4. Determine level from total XP: Lv1 Beginner 0–499, Lv2 Builder 500–999, Lv3 Grinder 1000–1999, Lv4 Creator 2000–3999, Lv5 Machine 4000+.
   Build 10-char XP bar: ████████░░ (filled chars = floor(pct/10)).

5. Rewrite `00-RAW/gamification/state.md` with updated values.

6. Rewrite `Dashboard.md` at vault root with updated Status table (level, XP, bar, streak, weekly videos), #1 Priority (✅ or ❌), Bumped Tasks (from last 3 daily notes), weekly table, and 7-day XP log.

## Step 5: Final summary to the user

Print one clean summary:

```
✅ Evening routine complete!

📓 Daily note → 00-RAW/Daily/{{date}}.md
📅 Calendar → {{N}} blocks added for tomorrow
🎮 XP → +{{xp_today}} XP earned (total: {{new_xp}} | Level {{level}} — {{level_name}})
🔥 Streak: {{streak}} days
{{if level up: 🎉 LEVEL UP! You're now Level {{level}} — {{level_name}}!}}
```

## Notes

- Keep the daily note under 50 lines.
- Do not add motivational fluff. Be factual and honest.
- If the user didn't mention something specific for a section, write "Nothing noted."
- The note is the source of truth for Steps 3 and 4 — be accurate.
